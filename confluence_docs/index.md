# Confluence Documentation Index

This directory mirrors the Confluence space structure. Use each page as a standalone Confluence page or import the Markdown directly.

## Core pages
- `application-pattern.md`: Patterns used across plan discovery, plan building, ordering, and apply dispatch.  
- `testing-steps.md`: Walks through unit runs, the integration script, and verification tasks.  
- `diagrams-workflow.md`: Links to the workflow, sequence, and class diagrams plus guidance for rendering Mermaid artifacts.

## Knowledge share
- `knowledge-share/resources.md`: Lists the documents and diagrams to surface during onboarding.  
- `knowledge-share/sessions.md`: Suggests agendas, shared artifacts, and follow-up actions for knowledge-share meetings.

## Usage tip
Link each Markdown file to a Confluence page under the same pathname. For diagrams, attach the PNG exports from `diagrams/` and embed the Mermaid source for future updates. Keep this index updated when adding new pages so reviewers always find the latest entry points.
